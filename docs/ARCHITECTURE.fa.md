# ساختار پروژه

برنامه یک سرویس Node.js 24 با رابط وب واکنش‌گرا و SQLite است. وابستگی زمان اجرا به بسته خارجی ندارد. ورود پایدار، جداسازی برندها، رسانه خصوصی و زمان‌بند داخل همین فرایند اجرا می‌شوند.

| مسیر | مسئولیت |
| --- | --- |
| `server.mjs` | ورودی ثابت برای اجرای محلی و مدیر فرایند هاست |
| `src/http` | درخواست HTTP، رسانه و سیاست‌های امنیتی |
| `src/accounts` | حساب، نشست، بازیابی و عضویت برندها |
| `src/channels` | مقصدها، تنظیم اتصال و بررسی دسترسی |
| `src/content` | ساخت متن و عملیات کتابخانه |
| `src/publishing` | ارسال، کنترل پیام، رسید و زمان‌بندی |
| `src/storage` | SQLite و مهاجرت ساختار داده |
| `src/infrastructure` | شبکه، مسیر اتصال و تشخیص خطا |
| `src/ai` | اتصال هوش مصنوعی و کمک متنی |
| `src/calendar` | سرویس تقویم محتوا |
| `src/tracking` | لینک‌های قابل اندازه‌گیری |
| `public` | فایل‌های عمومی رابط وب، فونت و لوگو |
| `scripts` | بررسی کد، بسته انتشار و بازیابی حساب |
| `scripts/windows` | راه‌اندازی و مدیریت سرویس ویندوز |
| `tests` | آزمون‌های خودکار و شبیه‌ساز شبکه |
| `docs` | راهنمای کاربری، معماری و نقشه راه |
| `deploy` | نمونه تنظیمات نصب عمومی |
| `.github/workflows` | اعتبارسنجی و تولید بسته در GitHub |

`DATA_DIR` خارج از کد نگهداری می‌شود. حساب‌ها، رسانه، توکن‌های رمزگذاری‌شده، کلیدها و دیتابیس‌ها در بسته انتشار قرار نمی‌گیرند. پوشه‌های محلی `qa-local`، `review-evidence` و `backups` ابزار و شواهد توسعه‌اند و در گیت و بسته محصول نیستند.

## قواعد تغییر

واردسازی‌ها صریح و نسبی‌اند. ماژول سرور مسیر ریشه نصب را از `import.meta.url` پیدا می‌کند؛ اجرای برنامه از مسیر دیگر نباید محل داده را جابه‌جا کند. در نصب واقعی همیشه `DATA_DIR` مطلق تعیین شود. مسیر فایل‌های مرورگر ثابت مانده تا کش، لینک‌ها و تنظیمات امنیتی تغییر نکنند.

پیش از انتشار: `npm run check`، سپس `npm test`، بررسی مرورگر موبایل و دسکتاپ، و `npm run package`. تنها فایل‌های فهرست مجاز وارد بسته می‌شوند و هش هر فایل در `release.json` ثبت می‌شود.
