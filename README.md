# Mohta1 | محتوان

پلتفرم مدیریت محتوای کانال های دیجیتال 

## نسخه قابل بازیابی

نسخه فعلی `v0.1.5` است و شماره داخلی برنامه هم `0.1.5` است
[تغییرات نسخه](CHANGELOG.fa.md) شامل تقویم محتوایی، کنترل پیام های منتشر شده و ساده سازی ویرایشگر است

تگ `v0.1.0` نسخه اولیه این مخزن و تصویر کد پروتوتایپ پیش از اصلاحات جدید است
شماره داخلی برنامه در این تصویر `0.12.0` است و با شماره نسخه مخزن تفاوت دارد
این مخزن دیتابیس، حساب کاربری، رسانه شخصی، کلید رمزگذاری و توکن اتصال ندارد

## اجرا

Node.js 24 لازم است

```powershell
$env:DATA_DIR = Join-Path $PWD 'data'
node server.mjs
```

در `http://127.0.0.1:8787` حساب و برند خود را بسازید
اطلاعات نصب فقط در مسیر `DATA_DIR` نگهداری میشود و نباید در گیت قرار بگیرد

```powershell
node --test tests/*.test.mjs
```

[راهنمای کامل فارسی](README.fa.md)

## بازیابی کد

```powershell
git clone https://github.com/MohamadeRahbar/mohta1.git
cd mohta1
git checkout v0.1.5
```

برای بازیابی پروتوتایپ اولیه میتوانید تگ `v0.1.0` را انتخاب کنید
تگ های مخزن فقط کد را بازیابی میکنند داده ها و کلیدهای نصب به پشتیبان جداگانه نیاز دارند
